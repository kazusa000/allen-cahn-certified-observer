# R5-K：保持三次项耗散的对角收缩度量

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run
- Verification Status: UNVERIFIED
- Version Label: r5_k_plan_v1
- 方程：一维半离散 Allen--Cahn，齐次 Dirichlet 边界
- 参数：\(\nu=0.005\)，三个固定局部平均传感器
- 第一阶段网格：\(n=31\)
- 请求收缩率：\(\alpha=0.1\nu\pi^2\)
- 数据：不使用训练、验证或测试样本

## 研究问题

R5-J 表明，任意斜的 Sylvester 坐标虽然能把线性部分精确变成稳定标准形，却可能破坏
Allen--Cahn 三次项在物理内积中的耗散性。本实验不再先指定完整线性标准形，而是直接问：

> 是否存在正对角能量和三传感器输出注入，使线性误差系统收缩，同时严格保留三次项的
> 全局耗散符号？

## 可证明的结构

令

\[
\dot e=A_he-B_hC_he-D(u,e),
\qquad
D(u,e)=(u+e)^3-u^3.
\]

寻找正对角矩阵

\[
M_h=\operatorname{diag}(m_1,\ldots,m_n)>0
\]

以及 \(Y_h=M_hB_h\)，使

\[
A_h^\top M_h+M_hA_h-C_h^\top Y_h^\top-Y_hC_h
+2\alpha M_h\prec0.
\]

这是关于 \(m\) 和 \(Y_h\) 的凸半正定可行性问题。若它成立，取

\[
T_0=M_h^{1/2},\qquad z=T_0e,
\]

则线性部分在 \(z\) 的欧氏能量中至少以 \(\alpha\) 收缩。

更重要的是，因为 \(M_h\) 为正对角矩阵，

\[
e^\top M_hD(u,e)
=\sum_i m_i e_i^2(3u_i^2+3u_ie_i+e_i^2)\ge0.
\]

所以真实变换后的三次项对所有 \(u,e\) 都不会破坏稳定性。由两部分直接得到

\[
\frac12\frac{\mathrm d}{\mathrm dt}\|z\|_2^2
\le-\alpha\|z\|_2^2.
\]

这正是“线性骨架由观测器设计稳定，真实非线性余项用能量估计处理”的结构。

## 第一阶段筛选

只在 \(n=31\) 求解，按顺序检查条件数上界

\[
\kappa(M_h)\le
4,16,64,256,1024,4096,16384,65536,10^6.
\]

每个问题固定 \(1\le m_i\le\kappa\)，使用 SCS。矩阵先按
\(\max(1,\|A_h\|_2)\) 归一化，再恢复物理尺度并独立计算：

- 归一化 Lyapunov 最大特征值；
- 实际线性收缩率；
- \(M_h\) 条件数；
- 输出注入范数；
- 对 \(\ker C_h\) 的必要条件；
- 随机点上的三次项符号，仅作为实现回归，不替代理论恒等式。

只有后处理得到的线性收缩率不低于 \(\alpha-10^{-7}\)，并且权重严格为正，才记为可行。

第一次执行时 CLARABEL 在首个半正定问题上直接抛出 SolverError，未生成任何科学结果。
修订后的入口把每次求解器失败单独记录，并使用支持相同半正定约束的 SCS；是否可行仍完全
由恢复到原尺度后的特征值检查决定，而不是由求解器状态单独决定。

## 顺序决策

1. 若某个条件数上界可行，冻结第一个可行解，再扩展到
   \(n\in\{31,63,127,191\}\)；
2. 若只在很大条件数下可行，先研究权重的网格趋势，不直接声称连续 PDE 结果；
3. 若到 \(10^6\) 仍不可行，则正对角全局度量路线结束，下一步转向有结构的块对角或
   状态依赖度量，并明确其非线性一侧界。
