## 研究问题

本实验把两个问题严格分开：

1. 已冻结的 `nu=0.005, q=3` checkpoint 能否通过独立样本和未见网格审计；
2. 当扩散系数改变、传感器数随不稳定模态数改变时，联合设计 `B,T_phi` 的训练机制能否复现。

不把同一个三传感器 checkpoint 机械外推到所有扩散系数，也不把三张参与训练的网格称为未见
网格泛化。

## 扩散系数与传感器数量

零状态线性化的模态增长率为

\[
\mu_k=1-\nu k^2\pi^2.
\]

主实验保持“比不稳定模态数少一个传感器”的相对欠观测难度；同数目传感器作为正对照：

| `nu` | 不稳定模态数 | 主实验 `q` | 正对照 `q` |
|---:|---:|---:|---:|
| 0.0050 | 4 | 3 | 4 |
| 0.0075 | 3 | 2 | 3 |
| 0.0100 | 3 | 2 | 3 |
| 0.0150 | 2 | 1 | 2 |
| 0.0200 | 2 | 1 | 2 |

所有配置保持总观测长度 0.20。传感器位置只允许由设计网格 `n=31` 的线性可观测性指标选择，
不得读取非线性 validation 或 test 轨迹。一个传感器配置必须避开使必要不稳定模态不可见的
对称位置。

## G1：冻结三传感器 checkpoint 审计

- 方程参数：`nu=0.005`；传感器：冻结的三个局部平均区间；
- checkpoint：冻结的 seed 1303、`rho=0.9`、50% 增益信赖域；
- evaluation-only：禁止梯度、优化器、checkpoint 写回或超参数搜索；
- fresh validation seed：1871；
- locked test seed：1901；
- validation 网格：31、47、63、95、127；
- locked test 网格：31、63、127、191、255；
- 每网格 validation collocation：4096；test collocation：8192；
- 每网格轨迹：6 个随机初值，加第四模态和最小观测方向的正负压力轨迹；
- 时间区间：当前 G1 保持 `[0,1]`，长时段和分布外初值留到 G3。

只有 fresh validation 的实用门通过才允许生成 seed 1901。严格门无论成败都完整报告，但不再
作为唯一的 test 解锁条件。

## 双层判据

### 严格证书指标

- collocation 和轨迹的最坏余量全部非负；
- 在线终点中位数不超过基线 1.05 倍，最大值不超过 1.10 倍；
- 全部结构门通过。

严格指标用于说明是否获得有限样本全点证书，不作为唯一工程放行条件。

### 实用泛化门

每个网格同时满足：

- collocation 收缩通过率至少 99.5%；
- collocation 1% 分位余量非负；
- collocation 最坏余量不低于 -0.10；
- 轨迹收缩通过率至少 99%；
- 轨迹 1% 分位余量非负，最坏余量不低于 -0.02；
- 在线终点误差中位数不超过基线 1.10 倍，最大值不超过 1.20 倍；
- 零纤维、谱界、Jacobian 和数值求逆结构门全部通过。

任何负余量都必须原样报告。实用门通过只能写成“经验泛化可用”，不能写成严格收缩证书。

## G2：方法复现

G1 完成后再推进：

- `q=2` 模型族：在 `nu=0.0075` 训练，零样本评价 `nu=0.010`；
- `q=1` 模型族：在 `nu=0.015` 训练，零样本评价 `nu=0.020`；
- 训练网格：31、63；validation 网格：47、95；locked test 网格：127、191；
- 每个模型族五个随机初始化；至少 3/5 个 seed 通过实用门才解锁 test；
- 严格通过 seed 数单独报告，不要求 5/5。

若零样本参数迁移失败，只能把失败参数降为新的校准任务；不得读取 test 后回头修改本轮配置。

## G3：分布外鲁棒性

仅在 IID 审计完成后运行，逐项报告退化曲线：更高频状态和误差、局部脉冲、多界面初值、
更大误差半径、`t=5` 长轨迹、独立噪声、共同噪声、偏置、传感器位置扰动和短时失效。
这些压力测试不包装为连续状态域定理。

## 对照和归因

每个配置至少保留：联合 `B,T_phi`、学得 `B` 加固定 `T0`、固定 LMI `B0,T0`、固定增益
nudging 和 `q=N_u` 正对照。最终模型的消融必须重新在同一 split 上计算，不沿用早期 checkpoint
的归因数字。

## 执行与停止

1. 本地 CPU 小样本只验证数据隔离、网格提升、checkpoint 只读性和结果格式；
2. 正式运行绑定干净且已推送的精确 Git commit；
3. G1 validation 失败时不读取 locked test，先报告失败维度；
4. G1 完成前不启动 G2 训练；
5. 不覆盖历史 `out/`，不修改原 checkpoint；
6. 科学门失败与程序崩溃分开报告，不自动重试崩溃运行。
