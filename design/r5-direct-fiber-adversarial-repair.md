## 研究问题

在固定

\[
\nu=0.005,\qquad q=3,\qquad n\in\{31,63,127\}
\]

且共享同一个物理模态增益 \(\Beta\) 和条件可逆变换 \(T_\phi\) 时，能否通过低模态
min--max 训练消除上一轮在 \(n=63\) 新 validation 集中出现的唯一坏点，同时保持其他网格、
因果轨迹、在线误差和可逆性不退化？

上一轮坏点只有前四个误差模态，且三个模型 seed 都在同一个样本附近失败。因此本轮检验的
假设是：失败主要来自固定训练池和零缓冲 CVaR 对最坏低模态组合覆盖不足，而不是网络容量、
高频尾部或真实轨迹动力学本身失败。

## 冻结内容

- 方程、\(\nu\)、三个传感器位置和网格 \(31,63,127\) 不变；
- 网络结构保持

  \[
  T_{\phi,h}(u,e)
  =V_{4,h}T_0[b+g_\phi(a,b)-g_\phi(a,0)]+(I-\Pi_{4,h})e;
  \]

- \(\rho=0.35\)、网络宽度 64、三层、增益 25% 信赖域不变；
- 使用已修正换基矩阵

  \[
  R=\operatorname{diag}(-1,-1,1,1),\qquad
  \Beta_0=\sqrt h\,RK,\qquad T_0=RP^{1/2}R^{\mathsf T};
  \]

- 从上一轮三个正式 checkpoint 分别继续训练，不交叉挑选 seed；
- 在线误差项和增益正则项保留；不恢复人为非线性目标缺陷。

## 唯一方法变化

### 1. 每轮确定性重采样

每个 epoch、每个网格重新生成独立 collocation，不再反复使用固定的 4096 点池。状态仍限制在
前八个物理模态且 \(\|u\|_\infty\le 1.25\)，误差仍在前十二个物理模态且
\(0.02\le\|e\|_h\le0.8\)。随机 seed 由模型 seed、epoch 和网格唯一确定并写入结果。

### 2. \(n=63\) 低模态对抗搜索

在每次刷新时，对 128 个随机初值同时优化前八个状态系数 \(a\) 和前四个误差系数 \(b\)，
直接最小化真实误差动力学下的收缩率

\[
r_\phi(u,e)
=-\frac{\langle T_{\phi,h}(u,e),\partial_tT_{\phi,h}(u,e)\rangle_h}
{\|T_{\phi,h}(u,e)\|_h^2}.
\]

每步投影回上述紧域，保留最坏 64 点并回灌后续 \(n=63\) 训练批次。搜索不读取 validation
或 locked test 样本，也不把上一轮编号 471 的精确坐标加入训练。

### 3. 正余量训练

上一轮损失在余量刚过零后梯度消失。本轮把训练铰链改为

\[
\mathcal L_{\rm rob}
=\operatorname{CVaR}_{10\%}
\left[\max\{0,\delta-(r_\phi-\alpha)\}^2\right],
\qquad \delta=0.04.
\]

这要求训练点不仅通过 \(r_\phi\ge\alpha\)，还形成 0.04 的经验缓冲。

## 分阶段运行与信息隔离

1. **实现检查**：本地 CPU 小样本只检查梯度、投影、确定性和文件格式，不产生科学结论。
2. **校准**：只用模型 seed 1303；训练不读取 validation，训练后在已经消费过的 seed 1851
   上评估。只有三个网格全部门通过且最坏 collocation 余量至少为 \(+0.02\)，才冻结配置。
3. **正式 validation**：固定配置后训练 seed 1301、1302、1303；使用从未读取的 seed 1871。
   至少两个 seed 通过全部网格、轨迹、在线误差和结构门，才允许读取 locked test。
4. **locked test**：仍使用 seed 1901，只评估 validation 中选中的模型；不根据 test 调参或重跑。

## 预注册运行配置

- 针对微调：40 epochs，每 epoch 24 steps，batch size 256；
- 每 epoch 每网格重采样 2048 点；
- 每 2 epochs 刷新一次 \(n=63\) 对抗池；128 restarts，15 个投影梯度步，步长 0.02，保留 64 点；
- \(\delta=0.04\)；
- 增益学习率 \(10^{-4}\)，变换学习率 \(3\times10^{-4}\)；
- validation 每网格 4096 collocation；locked test 每网格 8192 collocation；
- 因果轨迹门、在线终点误差门、结构可逆性门与上一轮完全相同。

## 成功判据

正式成功必须同时满足：

1. 三个模型 seed 中至少两个通过全门；
2. 对每个通过模型和每个网格，validation collocation 最坏余量非负；
3. validation 因果轨迹保存点最坏余量非负；
4. 终点误差中位数和最大值相对 \(B_0\) 分别不超过 1.05 和 1.10；
5. \(T_\phi\) 的零纤维、谱界、采样 Jacobian 与数值求逆审计全部通过；
6. 若进入 locked test，选中模型在三个网格的全部 test collocation 和轨迹也必须通过同一门。

即使有限样本全部通过，也只称为“跨网格有限域经验最坏证书”，不外推为连续 PDE 紧集上的
严格全局定理。

## 停止规则

- 若校准仍不能达到 \(+0.02\) 缓冲，不消费 seed 1871；
- 若正式 validation 少于两个 seed 通过，不读取 seed 1901；
- 若 locked test 失败，完整报告失败，不根据 test 修改配置；
- 不通过继续扩大 \(\rho\)、网络或增益域来追逐单个点。

## 校准修订 1（正式 validation 前）

第一版单 seed 校准在已消费的 seed 1851 上失败，因此没有读取 seed 1871。虽然对抗搜索把其
发现的最坏余量从约 \(-0.390\) 改善到 \(-0.087\)，但最终 validation 最坏余量在
\(n=31,63,127\) 分别为 \(-0.033,-0.086,-0.098\)。结构和全部轨迹仍通过，但共享模型发生
跨网格遗忘。checkpoint 对比显示，增益参数相对变化约 7.9%，而变换参数相对变化约 172%，
状态依赖诊断 \(\eta_u\) 从约 0.002 增至 0.105；失败主要是 \(T_\phi\) 为追逐单网格对抗点
发生过大漂移。

因此在不改变模型容量、\(\rho\) 和增益域的前提下，只修订训练策略：

1. 对抗搜索由只做 \(n=63\) 改为三个网格都做，防止共享参数牺牲 \(n=31,127\)；
2. 每个批次同时回放上一轮固定训练池和本轮在线重采样，防止遗忘；
3. 冻结一份原 checkpoint 作为 teacher，对 \(B\) 和 \(T_\phi\) 加函数锚定，但学生模型中的
   \(B,T_\phi\) 仍联合更新；
4. 已消费 seed 1851 的编号 471 及其小邻域可作为 calibration-derived hard replay。该点不再
   被当作样本外证据；真正的泛化只由尚未读取的 seed 1871 和 locked test 1901 判断；
5. 提高最坏收缩项相对在线项的权重，并降低微调学习率，避免在线均值掩盖少数坏点。

修订后的单 seed 校准仍必须在 seed 1851 上达到全部网格通过且最坏余量至少 \(+0.02\)，否则
仍不进入正式 validation。此次修订属于正式验证前的透明 calibration，不追溯改写第一版失败。

## 校准修订 2（正式 validation 前）

第二版仍未过门，最坏 validation 余量为 \(-0.061,-0.098,-0.098\)。不过，第一轮 2048 点
validation 的原编号 471 已经转为正余量；新的失败全部来自其他纯前四模态点。这证明精确坏点
本身已修复，但同类低模态方向还没有统一修复。

第二版的状态依赖诊断仍从原 checkpoint 的约 0.002 增至 0.068。由于完整收缩率包含

\[
D_uT_\phi(u,e)\partial_tu,
\]

过强的新增状态依赖会在别的状态上制造新坏点。第三版因此保留原 checkpoint 已经学到的条件
支路并冻结它，只联合训练 \(B\) 以及 \(T_\phi\) 的误差支路和输出层；模型仍然非线性依赖
\((u,e)\)，但针对修复不能再任意放大 \(D_uT_\phi\)。优化使用 80 epochs 和余弦降学习率，
其余第二版回放、三网格对抗、正余量、teacher 锚定与信息隔离不变。

这是进入 seed 1871 前最后一次方法校准。若仍不能在 seed 1851 上达到 \(+0.02\)，停止训练
技巧搜索，并把结论改为：当前结构/信赖域需要数学容量调整，而不是继续追逐随机 seed。

## 容量修订（共同 LMI 诊断后）

第三版把 \(\eta_u\) 控制在 0.0037，但仍未通过，确认训练技巧不是主因。随后进行了两个不读取
新数据的容量诊断：

1. 只覆盖前三个网格的前四模态时，共同 LMI 在条件数上限 16 时可行；
2. 把每个网格的全部模态纳入，并保持当前“前四模态用共同度量、高频尾部恒等”的结构时，
   通过严格 Schur 补压缩得到的共同 LMI 在条件数上限 16 至 4096 均不可行。

第二项说明当前局部结构受到完整观测反馈产生的低--高模态耦合限制。作为进入更大结构改动前的
最后一个容量校准，把残差可逆预算由 \(\rho=0.35\) 放宽到 \(0.65<1\)，把增益信赖域由 25%
放宽到 50%。这仍保证 \(T_\phi\) 关于误差全局可逆，但允许更大的低模态几何修正。模型从原
checkpoint 精确初始化；条件支路继续冻结，其他对抗、回放和信息隔离不变。

若该容量校准仍不能通过 seed 1851，则不进入 seed 1871；下一条路线必须改变“高频恒等”的
结构本身，而不能再把失败归因于训练轮数、随机池或单个坏点。

## Min--max 实现修正

容量校准中，三个网格在同一刷新轮次的最佳对抗最坏余量已达到 \(-0.0063\)，各单网格都曾
出现正余量，但后续又退回负值。检查训练器发现，每次刷新会用新对抗池替换旧池，模型因而在
不同坏方向之间循环遗忘。严格说这不是约束生成式 min--max，因为已经发现的活动约束被删除。

修正为累积对抗记忆：每个网格的新坏点追加到历史约束集；每个训练批次一半使用最新坏点，
一半从全部历史坏点中抽样。记忆上限 2048 点/网格，本实验最多产生 1280 点/网格，因此不会
触发截断。模型容量、\(\rho=0.65\)、50% 增益域、条件支路冻结和其余损失均不再改变。

这一步属于对 min--max 实现语义的修复，而不是继续搜索超参数。仍只使用 seed 1851 校准；
通过 \(+0.02\) 门后才允许读取 seed 1871。
